隱私權政策

最後更新：2026-11-22

1. 適用範圍

本政策適用於「YT 影音團隊 Drive 上傳工具」（以下稱「本工具」）。本工具是擁有者個人使用的自動化程式，只由擁有者本人以自己的 Google 帳號授權。

2. 存取的 Google 使用者資料

本工具透過 Google Drive API 存取下列資料：

  • 在擁有者指定的 Google Drive 資料夾內建立子資料夾與上傳檔案（影片、字幕、圖片、文字檔）。
  • 讀取該資料夾與其子資料夾的檔案名稱、大小與連結，用來核對上傳結果與避免重複題目。
  • 讀取擁有者指定的音樂資料夾內的檔案，作為影片配樂。

本工具不會讀取或修改指定資料夾以外的任何檔案。

3. 資料的使用

取得的資料只用於產出與交付擁有者自己的影片草稿。本工具不會把任何 Google 使用者資料用於廣告、分析、訓練模型，或任何與上述目的無關的用途。

4. 資料的分享

本工具不會把 Google 使用者資料提供給任何第三方。影片成品只存放在擁有者自己的 Google Drive。

5. 資料的儲存與保護

OAuth 權杖只以加密方式存放在擁有者自己控制的雲端執行環境的機密設定中，不會寫入程式碼、日誌或版本控制系統。權杖可由擁有者隨時在 Google 帳戶的第三方存取權設定 撤銷。

6. 使用者權利

本工具唯一的使用者就是擁有者本人。擁有者可以隨時撤銷授權、刪除 Drive 內的檔案，或停止使用本工具。

7. Google API 服務使用者資料政策

本工具對 Google API 取得之資訊的使用，遵守 Google API 服務使用者資料政策，包括其中的有限使用規定。

8. 聯絡方式
